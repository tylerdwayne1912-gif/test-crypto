Quick Start

Set up the wallet system in five steps.
  1. Go to XPUB Config and paste your ETH extended public key.
  2. Set your Hot Wallet address — where user deposits sweep to.
  3. Open the App and sign up — your user is auto-provisioned a unique address.
  4. Check User Wallets to see every user, their address, and their balance.
  5. Use Deposits to detect incoming funds, then build a sweep.

Production flow:
1. User deposits to unique address derived from your XPUB
2. Detect deposit and approve in Deposits panel
3. Build sweep → sign with hardware wallet → broadcast
4. When hot wallet exceeds threshold, move excess to cold storage
5. When hot wallet runs low, refill from cold with multi-sig approval
